# Joshuto

以本地 `yazi/yazi.toml`、`yazi/keymap.toml` 及 Yazi 26.1.22 默认主题为基准，
适配本机 Joshuto 0.9.9。配置目录整体链接到 `~/.config/joshuto`，修改后重启生效。

## 已对齐

- 固定 `1:4:3` 三栏；自然排序、目录优先、不区分大小写、默认隐藏点文件。
- 显示大小、滚动留白 5 行，文件图标使用 Yazi 的字形。
- 配色跟随终端 ANSI 调色板：目录蓝、可执行文件绿、图片黄、媒体紫、压缩包红、文档青。
- 文本使用 `${EDITOR:-vim}`；媒体使用系统打开；`O` 可选择 Reveal / EXIF。
  压缩包按本地 Yazi 规则优先 Reveal，macOS 定位到 Finder，Linux 打开所在目录。
- 文本预览不换行，Tab 为 2 个空格；支持 `J` / `K` 上下滚动。

## 预览

`preview_file.sh` 需要 Python 3；可选工具缺失时回退到纯文本或文件信息。

| 类型 | 实现 |
| --- | --- |
| 文本、代码、无后缀文本 | `bat` / `batcat` 高亮，缺失则读取文本 |
| JSON | `jq` 格式化，无效 JSON 回退文本 |
| PDF | `pdftotext` 提取前 10 页文字 |
| ZIP、TAR、7z 等 | `7zz` / `7z` / `bsdtar` / `unzip` 列出内容 |
| 常见位图 | Joshuto 原生图片渲染，附带文件信息 |
| 音视频 | `ffprobe` 元数据，缺失则显示文件类型 |
| 未知二进制 | 文件类型与大小，不输出原始二进制 |

主配置允许预览不超过 100 MB 的文件。脚本最多返回 128 KiB / 1000 行；
超过 2 MiB 的文本只读取开头 128 KiB。外部转换单次最多 4 秒、总预算 6 秒，
避免损坏文件或缺失工具使预览一直等待。Joshuto 0.9.9 只接受脚本退出码 0。

cmux / Ghostty 使用显式 `preview_protocol = "kitty"`，避开 0.9.9 自动探测时
将终端回复误当按键的问题。图片已在 cmux 实测显示。其他不支持 Kitty 图像的终端
可改成 `"halfblocks"`；不要直接改回 `"auto"`。`bat` 使用内置 `base16` 主题，
跟随终端配色。

## 与 Yazi 的差异

Joshuto 的图标不能独立设颜色，MIME 配色以扩展名近似；完整状态栏、边框颜色、
链接目标展示、悬停圆角没有对应配置。图标需要 Nerd Font 或终端字体回退。
新建使用终端提示，`Tab` 保留切标签（没有 Yazi spot）；`l` 也会打开普通文件。
不提供 Yazi 的前进历史、反向可视取消选择及原生 fd/rg 搜索。
`-` / `_` 使用当前选择建立链接，不能从 Yazi 式复制缓冲区取文件。
图片按预览区域缩放，没有与 Yazi `max_width=600` / `max_height=900` 等价的像素上限；
PDF 和视频目前为文字／元数据预览，不生成页面或视频缩略图。

配置依据：[Joshuto 0.9.9](https://github.com/kamiyaa/joshuto/tree/v0.9.9/config)、
[Yazi 26.1.22 默认配置](https://github.com/sxyazi/yazi/tree/v26.1.22/yazi-config/preset)。
