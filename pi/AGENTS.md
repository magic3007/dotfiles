# 全局偏好

## 语言（硬约束）

- 从回复的第一个字符起就用简体中文，包括开场、进度说明、提问、总结；不得先用
  英文写正文再补一句中文。
- 除非用户这一轮主动使用英文，才跟随英文。
- 以下内容保持原文不翻译：代码、标识符、命令、文件路径、报错信息、引用文本。

## Toil Offloading（默认启用）

遇到可切分的实质工作，默认委派给 subagent，而不是自己埋头做完；根 agent 出判断，
subagent 出量。

- 能切就派，判据与不可委派边界以 skill 为准，不要凭直觉放宽或收紧。
- 用 `subagent` 工具（`afang-subagent` 扩展）。不要用 shell 起 claude / codex /
  gemini 等 CLI 当子进程。
- 委派前必须写清合同（目标、输入路径、所有权边界、已定方案、验收标准、返回格式）。
  只发一句话目标等于让廉价模型猜，比不委派更糟。
- 并行写入合同不得落在同一批重叠路径上。
- 不以 subagent 的成功消息作为验收依据，必须自己核对产物。
- 不适用于：一句话能答完的问题、纯解释、单个小编辑、需要连续上下文推理的紧耦合改动。

方法论、agent 分工、模型分级、风险分级、合同写法，唯一来源见
`toil-offloading-pi` skill；非平凡委派前读取。
