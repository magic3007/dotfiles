# 全局偏好

## 语言

- 始终使用中文回复。
- 代码、标识符、命令、文件路径、错误信息原文保持不变。

## Toil Offloading（默认启用）

遇到可拆分的实质工作（多文件调研、独立子任务、重复性验证、跨模块批量改动）时，
默认不自己埋头做完，而是作为编排者委派给 subagent：

- 根 agent 保留：目标澄清、任务分解、跨切面分析、架构/优先级决策、边界划分、
  冲突解决、最终集成与验收
- 委派出去：仓库检索、诊断、实现、重构、数据提取、产物生成、聚焦验证
- 用 `subagent` 工具（`afang-subagent` 扩展）；可拆分时优先并行/chain 模式
- **按任务性质路由到外部 API 来源**（主 agent 自行判断）：
  - `dspix`（DeepSeek Flash）— 机械/检索/格式化：目标搜索、文件盘点、字段提取、
    格式转换、重复性检查、小的独立编辑、跑已有测试
  - `glmpix`（GLM-5.3-Flash）— 诊断/推理/review：根因定位、模糊 bug、跨文件分析、
    实现权衡、独立代码审查
  - 不确定或需要完整工具与长上下文时，用原生 `worker` / `scout` / `planner` / `reviewer`
  - 判断依据是**任务性质而非大小**：大而机械的给 dspix，小而需推理的给 glmpix
  - dspix 若报告超出机械范围，带证据改派 glmpix，不要原地重试
- 委派前必须写清 assignment contract（目标、输入路径、所有权边界、执行步骤、
  验收标准、返回格式）；不要只发一句话目标
- **不适用于**：一句话能答完的问题、纯聊天/解释、单个小编辑、需要连续上下文
  推理的紧耦合改动 —— 这类直接自己做更快

完整方法论见 `toil-offloading-pi` skill，遇到非平凡委派时读取。
