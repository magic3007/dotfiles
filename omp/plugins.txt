# omp plugins, installed by scripts/omp-plugins.sh (from install.conf Phase 2,
# after bun and omp are installed — omp shells out to `bun install`).
#
# One `omp plugin install` spec per line; blank lines and # comments are
# ignored. npm specs support the feature bracket syntax (`pkg[a,b]`, `pkg[]`,
# `pkg[*]`). The installed plugin trees, bun.lock and omp-plugins.lock.json are
# runtime state and stay out of git (see omp/README.md, "Plugins").
#
# pi-fff: FFF-backed fuzzy file finding and content search.
# Overrides the built-in read/grep tools while its features are enabled
# (toggle with /fff-features inside omp). Its `autocomplete` feature stays off —
# it breaks omp's `@` completion; see omp/README.md, "Plugins".
npm:pi-fff
#
# omp-model-gateway: adds a `/login` entry that registers any base-URL + API-key
# gateway and discovers its chat models. It owns
# ~/.omp/agent/gateways-login.json, which is where the `volcengine` provider
# (the default model's provider) and `mafia` come from. Without it the
# modelRoles.default selector cannot resolve; see omp/README.md, "Gateway
# provider（gateways-login.json）".
npm:omp-model-gateway
#
# omp-herdr-agents: async subagents in Herdr panes (`subagent`,
# `subagent_send`, `worktree_*`, …) whose children are omp processes. Needs
# the `herdr` CLI and HERDR_ENV=1, i.e. omp started inside a Herdr pane, plus
# a persistent session (`--no-session` has no session file to hand the child).
# This is the local fork of pi-herdr-agents ported to omp; the published package
# is the only copy that runs children as omp. A filesystem path also works here
# (for an unpublished local build) — see omp/README.md, "Plugins".
npm:omp-herdr-agents
#
# omp-prompt-polish: `/polish [style] [draft]` and `ctrl+alt+p` rewrite the
# composer draft into a better prompt through an ephemeral side turn (session
# model, result never enters the transcript) and write it back into the
# composer. Port of the DSH plugin magic3007/dsh-prompt-polish; optional config
# at ~/.omp/agent/extensions/prompt-polish.json — see the repo README.
github:magic3007/omp-prompt-polish
