# omp plugins, installed by scripts/post-install.d/40-omp-plugins.sh.
#
# One `omp plugin install` spec per line; blank lines and # comments are
# ignored. npm specs support the feature bracket syntax (`pkg[a,b]`, `pkg[]`,
# `pkg[*]`). The installed plugin trees, bun.lock and omp-plugins.lock.json are
# runtime state and stay out of git (see omp/README.md, "Plugins").
#
# pi-fff: FFF-backed fuzzy file finding and content search.
# Overrides the built-in read/grep tools while its features are enabled
# (toggle with /fff-features inside omp). Its `autocomplete` feature stays off —
# it breaks omp's `@` completion; see omp/README.md, "Plugins".
npm:pi-fff
#
# omp-model-gateway: adds a `/login` entry that registers any base-URL + API-key
# gateway and discovers its chat models. It owns
# ~/.omp/agent/gateways-login.json, which is where the `volcengine` provider
# (the default model's provider) and `mafia` come from. Without it the
# modelRoles.default selector cannot resolve; see omp/README.md, "Gateway
# provider（gateways-login.json）".
npm:omp-model-gateway
