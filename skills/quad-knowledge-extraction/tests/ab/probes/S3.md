# 探针集 S3（盲测：只依据给定的技能文件回答，不得查看其它文件）

请只读分配给你的那一份 `SKILL.md`，然后回答下面 5 个问题。**不要**去读任何其它技能文件、会话记录或目录。

## Q1（命中题）
GitHub Actions 上 `npm test` 必失败：

```
FAIL  test/billing.spec.ts
AssertionError: expected 1999 to be 2000
```

本地连续 20 次全绿，重跑同一个 commit 也必失败。这次 PR 只改了测试文件里一个断言的字符串文案。
问：这份技能适用于这个场景吗？如果适用，第一步该执行什么命令、期望看到什么输出？

## Q2（近似干扰题）
另一次 CI 失败信息是：

```
npm ERR! code EINTEGRITY
npm ERR! sha512-... integrity checksum failed when using sha512
```

本地同样绿。问：这份技能适用于这个场景吗？给出你的判断依据。

## Q3（可复核题）
半年后要确认这份技能里的结论仍然成立，具体要跑哪些命令？逐条列出可粘贴执行的命令。

## Q4（校准题）
这份技能里哪些结论**没有**被实际验证过？逐条列出。

## Q5（边界题）
什么情况下不该用这份技能？给出至少一条可观测的判断信号。
