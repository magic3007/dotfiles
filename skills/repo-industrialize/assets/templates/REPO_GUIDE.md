## 确定性检查

规则正文在 `.repo-std/corrections.yml`，检查实现在 `.repo-std/checks/`。

```bash
python <corrections.py 路径> --ledger .repo-std/corrections.yml verify   # 台账自身合法
python <corrections.py 路径> --ledger .repo-std/corrections.yml run      # 干净仓库必须全过
python <corrections.py 路径> --ledger .repo-std/corrections.yml prove    # 违规样本必须被抓到
```

新增一条规则的流程：写可判定的一句话 → 写检查与违规样本 → `corrections.py add` 登记 → 接进 CI。
